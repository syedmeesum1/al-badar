# Al-Badar Hosiery (Faisalabad)
## Custom Wholesale Website & Production ERP Ecosystem

Official digital platform and production ERP showcase for **Al-Badar Hosiery, Faisalabad**.

- **Business**: Al-Badar Hosiery
- **Specialization**: Knitwear & Undergarment Manufacturer (1x1 Ribbed Vests, Combed Cotton Briefs, Thermals, Polo Shirts)

---

### ✨ Features
1. **Interactive Textile Thread Particle Canvas**: Responsive woven cotton thread animation.
2. **Wholesale B2B Catalog**: Filterable catalog with tier wholesale pricing (per dozen/carton), fabric GSM, sizes, and sample request modals.
3. **Knitting & Stitching Floor ERP Simulator**:
   - Live circular loom speeds (RPM), fabric roll weight (kg), and needle status.
   - Stitching lines (1 to 4) worker outputs, targets, and defect rates.
   - Interactive QR bundle barcode scan simulation with live toast notifications.
   - Yarn warehouse cones/bags ledger with count classifications (20s, 30s, 40s).
4. **Dynamic Yarn Yield & Wholesale Cost Calculator**:
   - Calculates exact cotton yarn in KGs, bags (100 lbs standard), and cones.
   - Estimated production lead time in working days.
   - Estimated factory price per dozen and total wholesale batch quotation in PKR.
   - 1-click WhatsApp quote generator pre-filling all order specifications.
5. **Modern Light Executive Aesthetic**:
   - Clean, light color palette with crisp high-contrast typography and subtle borders.
   - Fully responsive across mobile, tablet, laptop, and 4K desktop screens.

### 🚀 Running Locally
```bash
# Clone the repository
git clone https://github.com/syedmeesum1/al-badar.git

# Navigate to directory
cd al-badar

# Run with any static server or Node.js
node server.js
```
Open [http://localhost:3456/](http://localhost:3456/) in your browser.
